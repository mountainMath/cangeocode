# French long forms for the street directions

Written out rather than derived from \`nar_lex_dirs\`, because picking
the longest French surface per canonical is ambiguous exactly where it
matters: \`SO\` has \`SUD-OUEST\` and \`SOUTHWEST\` at nine characters
each. The English canonicals are here too, since a Quebec row parsed
from an English surface form carries \`W\` rather than \`O\`.

## Usage

``` r
nar_qc_dirs()
```

## Value

A named character vector, canonical to French long form
