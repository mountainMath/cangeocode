# The last word of every numbered-road surface form

\`nar_is_street_type()\` claims most of them (\`ROAD\`, \`RD\`,
\`CONCESSION\`, \`ROUTE\`) but not all – \`MUN\` is a numbered-road word
and not a street type – so the leading-prose guard needs the lexicon's
own tails too.

## Usage

``` r
nar_road_tail_words()
```

## Value

A character vector
