# Find or fetch the RQA CSV

Find or fetch the RQA CSV

## Usage

``` r
rqa_resolve_csv(csv = NULL)
```

## Arguments

- csv:

  An explicit path, or \`NULL\`

## Value

A list of \`csv\` (path), \`dir\` (extraction directory) and
\`temporary\` (whether this function created the directory and may
delete it)
