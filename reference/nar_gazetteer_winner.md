# One winner per input row

The highest-scoring reading, and on a tie the earliest candidate – which
is the baseline parse. A reading only displaces it by resolving to a
street this one does not.

## Usage

``` r
nar_gazetteer_winner(best)
```

## Arguments

- best:

  Scored rows carrying \`.row\`, \`.cand\` and \`score\`

## Value

\`best\`, one row per \`.row\`
