# The canonicalization language a province takes

Quebec's NAR street types are French (\`RUE\`/\`AV\`/\`BOUL\` run 94-100
missing province falls back to English, which is the majority form for
all but one of the thirteen.

## Usage

``` r
nar_prov_language(prov)
```

## Arguments

- prov:

  A character vector of two-letter province codes

## Value

A character vector of \`"en"\` / \`"fr"\`
