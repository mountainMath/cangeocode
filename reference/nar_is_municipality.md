# Is this token run a municipality NAR files addresses under?

Is this token run a municipality NAR files addresses under?

## Usage

``` r
nar_is_municipality(key, prov = NA_character_)
```

## Arguments

- key:

  A folded municipality key, as \[nar_mun_key()\] builds it

- prov:

  A two-letter province code, or \`NA\`

## Value

\`TRUE\` when the key names a real place
