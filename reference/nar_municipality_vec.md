# Address counts for a vector of municipality names

Address counts for a vector of municipality names

## Usage

``` r
nar_municipality_vec(mun, prov)
```

## Arguments

- mun:

  A character vector of municipality names as parsed

- prov:

  A character vector of province codes, recycled against \`mun\`

## Value

A numeric vector of address counts, \`NA\` where the name is not a place
