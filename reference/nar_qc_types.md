# French long forms for the street types

Derived from \`nar_lex_types\` rather than written out, so a type added
to the lexicon is expanded here without a second edit. For each
canonical, the longest surface marked French: an abbreviation is always
shorter than the word it abbreviates, so the longest surface is the
spelled out one. Accents fall out of the lexicon's own unaccented
surfaces (\`MONTEE\`, \`COTE\`), which the service reads either way.

## Usage

``` r
nar_qc_types()
```

## Value

A named character vector, canonical to French long form
