# Is this token a street type in the given language context?

Is this token a street type in the given language context?

## Usage

``` r
nar_is_street_type(surface, lang = "en")
```

## Arguments

- surface:

  A character vector of already-folded surface forms

- lang:

  A character vector of \`"en"\` / \`"fr"\`, recycled against
  \`surface\`

## Value

A logical vector
