# The stored side of the unit comparison

Case, spaces and periods only – 592,561 of NAR's units are not upper
case and 16 are untrimmed. The vocabulary translation happens on the
input, in \[nar_unit_fold()\].

## Usage

``` r
nar_unit_sql(col)
```

## Arguments

- col:

  The stored unit column, qualified

## Value

A SQL fragment
