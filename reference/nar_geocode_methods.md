# Validate and normalize the \`method\` argument

Partial matching, deduplication, and an error naming the tier that was
not recognized rather than the whole vocabulary. \*\*Order is
preserved\*\*, since order is the priority.

## Usage

``` r
nar_geocode_methods(method)
```

## Arguments

- method:

  What the caller passed

## Value

A character vector of tier names
