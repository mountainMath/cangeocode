# The parsed index of a remote NAR release, read at most once per session

The parsed index of a remote NAR release, read at most once per session

## Usage

``` r
nar_release_directory(url)
```

## Arguments

- url:

  URL of the StatCan release zip

## Value

The data frame \[nar_zip_directory()\] returns, with a \`prov\` column
